# GameScope

A Streamlit dashboard for exploring the Video Game Sales dataset. Includes interactive filters, KPIs, category counts, bar/line/scatter charts, a searchable catalog and dataset profiling.

## Run locally

Keep `app.py`, `vgsales.csv` and `requirements.txt` together. In a Python environment, run:

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

The app expects `vgsales.csv` beside `app.py`.
